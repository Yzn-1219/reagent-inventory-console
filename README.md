# 试剂出入库管理台

科研小组共用的**云端试剂台账**：多人协作、手机号登录、入库出库、批次盘点、导出台账。纯静态前端（HTML + 原生 JS + CSS，无框架、无构建步骤），数据存在云数据库，所有组员共享同一份。

> 面向实验室 / 课题组的轻量级试剂与耗材管理工具。为「荜茇、蒲公英等天然产物提取」这类需要按批次追踪余量的场景设计。

---

## 功能

| 模块 | 说明 |
| --- | --- |
| 概览 | 试剂品种、在库总量、低库存、零库存、库存价值、本月流水；最近入库 / 低库存 / 最近动态 |
| 试剂台账 | 按试剂查看总量与批次，支持搜索、分类筛选、库存状态筛选；行内展开看批次明细 |
| 入库登记 | 每批货建一个批次，批号默认「年+月+日」，登记单价、供应商、到货日期、存放位置 |
| 领用出库 | 按批次先进先出领用，可一次扣多个批次，记录领用人 / 用途 / 关联课题 |
| 出入库流水 | 全部明细，按类型 / 日期 / 关键词筛选；出库可撤销；**管理员可删除流水**（自动纠正库存） |
| 盘点 | 批次实盘核对，自动生成盘盈 / 盘亏调整流水 |
| 设置 | 账号（锁定 / 退出登录 / 改密码）、小组、成员与角色、单位、分类、存放位置、低库存预警线、导出 |

## 账号与权限

- **登录**：手机号 + 密码；首次使用或忘记密码走短信验证码。手机号即账号，一个手机号一个人，换设备同样可用。
- **小组**：用组口令或邀请二维码申请加入，管理员审批后进组。
- **角色**：
  - 管理员 —— 审批加入、移除成员、设为/取消管理员、**转让管理员**、**删除流水**
  - 组员 —— 台账、入库、出库、盘点、导出
- **管理员转让**：管理员 A 在「设置 → 小组成员」选中组员 B 发起转让，B 登录后在顶部提示条点「接受」才生效（A 降为组员、B 升为管理员）。需要**双方同意**，可撤回、可拒绝。

## 低库存预警

在「试剂台账 → 预警线」或「设置 → 低库存预警线」可**批量设置**每一条试剂的预警线，不必在入库时设置。库存 ≤ 预警线时，概览与台账标黄提醒（填 0 表示不预警）。

## 数据与同步

- 云端数据库为唯一真相源；本地 `localStorage` 只做离线只读缓存。
- 联网时才允许写入，断网状态下界面会提示「离线（只读）」。
- 每次进入小组、点击刷新会重新拉取台账、批次、流水与成员。

## 目录结构

```
index.html              入口
assets/app.js           界面层：视图渲染、事件、导出 Excel、弹窗
assets/store.js         数据层：登录会话、云端读写、权限、缓存
assets/app.css          样式（含移动端适配）
assets/xlsx.js          极简 xlsx 生成器（A4 横向、冻结表头、合计行）
assets/vendor/          云端 SDK 与二维码组件
```

## 部署

静态站点，任意静态托管即可。本地预览：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080
```

云端配置（`assets/store.js` 顶部 `PUBLIC_CONFIG`）为应用开通时下发，属于**前端可公开的 publishable key**，不是服务端密钥。

## 版本记录

**v2.2（2026-11-23）**

- 小组名称改为「只读展示 + 重命名」入口，仅管理员可见可改；普通组员看到「由管理员维护」
- **修正权限漏洞**：原 `rename_team` 只校验「是否组员」，任何组员都能改名；现在服务端强制要求 admin，并校验名称非空、最多 40 字
- 改名走弹窗而不是浏览器 `prompt`，支持自动全选与字数上限

**v2.1（2026-11-23）**

- 新增「我的小组」卡片：一个账号可同时加入多个小组，逐条显示角色与口令，点「进入」即时切换工作台
- 新增**退出小组**：服务端校验权限（唯一管理员且组内还有他人时需先转让），退出后空小组自动清理
- 新增「加入其他小组」入口：输入组口令提交申请，审批通过后出现在列表里；侧边栏小组卡片也可直接唤起切换
- 修复：卡片底部主按钮被通用样式覆盖导致不可见

**v2.0（2026-11）**

- 新增「退出登录」：彻底退出云端会话并清除本机登录信息，回到手机号 + 密码登录页（与「锁定」区分）
- 新增管理员**删除流水**：服务端校验管理员身份，按类型回滚库存（出库退回批次 / 入库作废未被领用的批次 / 盘点回退到调整前），并留档删除人与原因
- 新增**管理员转让**：发起 → 对方接受后由服务端完成角色互换，支持撤回与拒绝
- 入库批号默认按「年+月+日」自动生成，可改为厂家批号
- 新增低库存预警线**批量设置**入口，台账直接显示每条试剂的预警线
- 全站界面优化：表单分段、表格小屏改为卡片式列布局、按钮与提示条统一、加载与空态细节

**v1.0（2026-11）** 首个可用版本：台账 / 入库 / 出库 / 流水 / 盘点 / 导出台账 / 小组协作。
